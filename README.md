### 🧠 Opportunity-to-Project Agent

I got tired of seeing interesting hackathons and then spending hours figuring out:

> What exactly are they asking?  
> Has someone already built this?  
> Is this even feasible?  
> How should I architecture it?

So I built an agent to do that work.

Give it an opportunity/hackathon URL and it researches the problem, looks for prior art, evaluates feasibility, and generates a **master context + architecture + build specification**.

Basically:

```text
"What should we build?"
          ↓
      AI agents
          ↓
 research + prior art
          ↓
    feasibility
          ↓
 architecture
          ↓
   build specification
```

→ [See the project](https://github.com/nakulmaurya/opportunity_agent_dashboard)
